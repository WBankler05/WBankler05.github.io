The idea

BanklerBot connects one structured knowledge vault to Claude so that the same system handles capturing ideas, tracking projects and tasks, and keeping long-term knowledge.

What I have built so far

  • Architected a PARA-based vault structure connected directly to Claude for natural-language search, summarization, and automation.
  • Built a live task dashboard.
  • Created a business ideation diligence pipeline that takes an idea from capture to a go or no-go decision.
  • Put the whole system under Git version control for a complete change history.

Next steps

Continue expanding the automations and the dashboard, and keep the system usable on its own without AI so that the knowledge stays durable.
